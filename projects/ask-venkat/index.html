Ask Venkat AI Portfolio Assistant

A retrieval-powered AI assistant built around my professional experience, projects and technical background — designed to let visitors explore my portfolio through conversation.

Try it live → View GitHub ↗
Project overview

Traditional portfolio websites are static. Visitors have to navigate through multiple pages to understand experience, projects, skills and technical depth.

Ask Venkat adds a conversational layer to the portfolio. Instead of searching manually, a visitor can ask a question and receive an answer grounded in curated information about my professional background.

The project combines a lightweight frontend, a Cloudflare Worker API, semantic retrieval through vector search and a language model that generates the final response using retrieved portfolio context.

01 / Problem

Make a portfolio easier to explore.

A portfolio contains useful information, but it still depends on the visitor knowing where to look.

I wanted to experiment with a different interaction model: allow someone to ask direct questions such as what kind of problems I have worked on, what technologies I use, or what experience I have in a particular area.

02 / Solution

Retrieval before generation.

Ask Venkat does not rely on a language model alone. Before generating an answer, the application searches a curated knowledge base containing information about my profile, employers, projects, education and skills.

The most relevant pieces of information are retrieved and passed to the model as context. This keeps the experience focused on the portfolio rather than turning it into a general-purpose chatbot.

05 / Decisions

Keep each part independent.

01

Keep the AI backend separate from the static portfolio so both can evolve independently.

02

Retrieve relevant portfolio information before asking the language model to generate an answer.

03

Keep the knowledge base curated rather than allowing the assistant to answer unrestricted questions.

04

Keep the user interface visually consistent with the rest of the portfolio instead of building a separate chatbot product.

06 / Learning

Building the full retrieval loop.

This project gave me a practical way to connect embeddings, vector search, retrieval and language models inside one end-to-end application.

It also reinforced an architectural principle I value: content, retrieval, API logic and presentation should remain modular enough to improve independently.
